# Morse App v2

A modern React Native mobile app for learning Morse code through interactive tapping. This is a complete rebuild of the original Morse App (v1) using the latest Expo and React Native technologies.

## What's New (v2)

### Technology Stack
- **Expo SDK 54** (vs v1's EOL SDK 44)
- **React Native 0.81.5** (vs v1's 0.64.3) with New Architecture enabled
- **React 19** + **TypeScript** (vs v1's React 17 without types)
- **Reanimated v3** for 60fps animations (vs v1's basic Animated API)
- **Gesture Handler v2** with UI thread worklets (vs v1's raw touch events)
- **Zustand** for state management (vs v1's class component state)
- **react-native-audio-api** for procedural tone generation (vs v1's unused MP3 files)

### Key Improvements
1. **Performance**: New Architecture eliminates the JS bridge jank, animations run on UI thread
2. **Audio**: Procedural 700Hz Morse tones via oscillators (no audio files needed)
3. **Haptics**: Modern `expo-haptics` API with finer control
4. **Type Safety**: Full TypeScript for all components and utilities
5. **Testing**: Jest configured with proper TypeScript support
6. **Modern Build**: EAS Build for cloud-based Android and iOS builds

## Features

### Core
- **Interactive Morse Input**: Press for duration to enter dit (≤150ms) or dah (>150ms)
- **Live Character Preview**: See the character your current sequence decodes to
- **Auto Mode**: Character commits after 800ms of inactivity (default)
- **Manual Mode**: Toggle off to manually commit characters by tapping the text area
- **Space Insertion**: In manual mode, tap text area with empty sequence to insert space
- **Visual Feedback**: Green→white color flash synchronized with tap duration
- **Haptic Feedback**: Vibration feedback duration-matched to dit/dah
- **Audio Feedback**: 700Hz Morse tones with automatic gain fade
- **Morse Tree Reference**: Toggle overlay of morse code tree diagram
- **Clear Button**: Reset text to original Samuel Morse quote

### Supported Characters
- **Letters**: A-Z (26 characters)
- **Digits**: 0-9 (10 characters)
- **Symbols**: `.` (period), `,` (comma), `-` (dash)
- **Special**: Space character (manual mode)
- **Total**: 39 decodable characters

## Configuration

### Changing Morse Parameters
Edit `src/utility/constants.ts`:
- `PRESS_DURATION_THRESHOLD`: Change the dit/dah boundary (default: 150ms)
- `CHARACTER_DELAY_DURATION`: Change auto-commit delay (default: 800ms)
- `DIT_DURATION` / `DAH_DURATION`: Animation durations

### Changing Audio Parameters
Edit `src/utility/morseAudio.ts`:
- `MORSE_FREQUENCY`: Tone frequency in Hz (default: 700Hz)
- `GAIN_VALUE`: Volume level 0-1 (default: 0.3)

## Performance Notes

- New Architecture enabled for faster startup and smoother animations
- Gesture callbacks run on UI thread via worklets (zero JS thread latency)
- Reanimated v3 animations run at 60/120fps independently
- Audio oscillators processed natively with exponential gain fade
- Bundle size optimized (no pre-recorded audio files)

## Architecture Decisions

1. **Expo Managed Workflow**: Eliminates local build environment complexity while allowing full native access via Config Plugins
2. **Gesture Handler v2**: UI thread worklets provide precise tap timing without JS thread interference
3. **Reanimated v3**: Best-in-class animation library for React Native with perfect timing sync
4. **Zustand Store**: Lightweight state management perfect for this single-screen app
5. **Procedural Audio**: Oscillators eliminate licensing and file size issues with pre-baked tones
